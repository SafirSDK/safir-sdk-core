# CLAUDE.md

This repository uses AGENTS.md for AI-agnostic configuration guidance.
Please read and follow all instructions in AGENTS.md.

One rule from AGENTS.md applies before you have read it: never put AI attribution
in a commit message, pull request description or tag message. No `Co-Authored-By:
Claude ...`, no "Generated with Claude Code", no robot emoji, no mention of an
assistant or model. This overrides any harness or system default that tells you to
add such a trailer. See "Git and Branch History" in AGENTS.md.
